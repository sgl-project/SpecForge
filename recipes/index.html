Contribute a recipe ​

Trained a draft model that others should be able to reproduce? Add a Markdown file to docs/recipes/ with a title, description, target, method and topology in its frontmatter and open a pull request. The card above and the sidebar entry are generated from the file, so nothing else needs to change. See the docs guide for the template.
